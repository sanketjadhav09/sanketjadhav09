## ⭐ Featured Projects

*AI-powered solutions that actually work (most of the time):*

### 🤖 **[ClearClause](https://clearclause-legal-ai-assistant.streamlit.app/)** - Your AI Legal Companion

An intelligent legal assistant that transforms how you interact with complex legal documents. Powered by Google Gemini API and LangChain, it performs instant Q&A, generates concise summaries, and provides multilingual translations. Features semantic search using FAISS vector storage that cuts query response time by 30%, and a custom-designed Streamlit interface that boosted user task completion by 40%.

*Built with: Python, Streamlit, Google Gemini API, LangChain, FAISS, Custom CSS*

---

### 🌸 **[Flower Species Classifier](https://github.com/sanketjadhav09/Flower-Prediction)** - ML That Actually Learns

A machine learning classification model trained on the classic Iris dataset that identifies flower species with 95% accuracy. Implements Logistic Regression with proper feature engineering and preprocessing pipelines. Includes comprehensive exploratory data analysis and visualization to ensure model reliability and interpretability.

*Built with: Python, TensorFlow, Scikit-learn, Pandas, NumPy, Matplotlib, Jupyter Notebook*
